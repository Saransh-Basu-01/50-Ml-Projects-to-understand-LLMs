# 50 ML Projects to Understand LLMs

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![Colab](https://img.shields.io/badge/Colab-Notebooks-orange.svg)](https://colab.research.google.com/)

This repository contains my practical journey through understanding Large Language Models (LLMs) by building 50 focused machine learning projects. Each project is a step-by-step implementation that explores the core concepts, architectures, and techniques behind modern LLMs.

This is a companion to the book "50 ML Projects to Understand LLMs," where I write and test the code while learning.
